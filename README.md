# Om Chaurasia — HPAIR 2027 Resume Website

A lightweight, responsive, typography-led resume website built with plain HTML and CSS.

## Files

- `index.html` — page content and semantic structure
- `styles.css` — visual system, responsive layout, accessibility and print styles

## Preview locally

Open `index.html` in a browser. No package installation, build step, external font, or JavaScript dependency is required.

## Publish

Upload both files to the root of a static hosting service (for example, GitHub Pages or Netlify). Keep `index.html` and `styles.css` in the same directory.

## Content notes

The website intentionally omits a skills list, LinkedIn/GitHub links, academic awards, leadership roles, and unverified dates because none were confirmed. The portfolio project is described as AI-assisted and directed/reviewed by Om.
